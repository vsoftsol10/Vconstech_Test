# VConstech Frontend

The VConstech frontend is a React 18 single-page application built with Vite 7. It uses React Router for navigation, Tailwind CSS for styling, and Axios for API requests.

## Development

```powershell
npm install
npm run dev
```

Set `VITE_API_URL` in a local environment file to the backend API base URL. Do not commit credentials or production secrets.

## Build and lint

```powershell
npm run build
npm run lint
```

For module instructions and the complete application stack, see the [Project User Guide](../PROJECT_USER_GUIDE.md) and the [repository README](../README.md).
